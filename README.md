# Neon Snake — Pixel/Arcade

Juego Snake arcade, ligero y adaptable a móvil. Está hecho únicamente con HTML, CSS y JavaScript: no requiere dependencias, instalación, servidor ni conexión a servicios externos.

## Cómo jugar

- **Mover:** flechas del teclado o `W`, `A`, `S`, `D`.
- **Pausa:** barra espaciadora.
- **Reiniciar tras perder:** `Enter`.
- En móvil puedes usar los botones de dirección o deslizar el dedo sobre el tablero.
- Come los orbes rosas para sumar puntos. Evita las paredes y tu propia cola.
- El récord se guarda en el navegador del jugador.

## Probar en local

Abre `index.html` en un navegador moderno.

## Publicar en GitHub Pages

1. Crea un repositorio en GitHub.
2. Sube **todos los archivos de esta carpeta** a la raíz del repositorio. Es importante que `index.html` esté en esa raíz.
3. En el repositorio, entra en **Settings → Pages**.
4. En **Build and deployment**, elige **Deploy from a branch**.
5. Selecciona la rama `main` y la carpeta `/(root)`, y pulsa **Save**.
6. Espera a que termine la publicación y abre la URL que GitHub Pages muestre en esa sección.

La publicación puede tardar unos minutos. Consulta la guía oficial: https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site
